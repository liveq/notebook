# 철망 바스켓 내부 칸막이 (무전기 + 폴드3)

버스 창문 레일에 건 철망 바스켓(내경 214 x 88, 깊이 30~40) 안에 넣는 칸막이 바스켓입니다.
바스켓 내경을 꽉 채우도록(212 x 86) 만들어서 바스켓 벽이 위치를 잡아 줍니다.

![도면](out/drawing.png)

| 칸 (운전석 -> 창문) | 안쪽 폭 | 벽 높이 | 넣는 것 |
|---|---|---|---|
| 수납칸 | 16.4 | 28 | 펜, 이어폰 등 (남는 깊이 활용) |
| 무전기 칸 | 34.0 | 앞 32 / 칸막이 50 | 라져+20 (공식 59x145x23, 케이스 포함 약 64x150x28) |
| 폰 칸 | 26.0 | 뒤 70 | 폴드3 접은 상태 (공식 158.2x67.1x16, 케이스 포함 약 162x71x20) |

- 각 칸 양쪽 끝 바닥에 케이블 구멍(22 x 14)이 있어 충전 단자 방향과 상관없이 꽂을 수 있습니다
- `spacer_radio.stl`, `spacer_phone.stl`: 기기 반대쪽 끝에 넣어 길이 방향으로 밀리지 않게 합니다

## 파일

| 파일 | 설명 |
|---|---|
| `out/insert.stl` | 본체 (바닥을 베드에 두고, 서포트 없이 출력) |
| `out/spacer_radio.stl`, `out/spacer_phone.stl` | 길이 방향 유격 메우는 블록 |
| `out/drawing.png`, `out/drawing.pdf` | 도면 |
| `out/params_used.json` | 이번 생성에 쓴 파라미터 |

## 바닥 걸림 핀 (철사 틈 2.4mm)

철사 사이 2.4mm 틈에 끼우는 두께 2.0mm 핀을 넣을 수 있습니다. 핀이 틈과 어긋나면 본체가 들뜨기 때문에, 위치를 실측하기 전에는 **꺼 둔 상태**로 생성됩니다.

1. 본체 운전석 쪽 바깥면(바스켓 안쪽 벽에서 1mm 안쪽)부터 2.4mm 틈 중심까지의 거리를 잽니다
2. 틈이 길이 방향(x)인지 깊이 방향(y)인지 확인합니다
3. `python3 make_insert.py --fin-y 43 --fin-dir x`처럼 실행합니다

이렇게 생성하면 바닥에 슬롯이 뚫리고 `fin.stl`이 따로 나옵니다. 핀은 옆으로 눕혀 출력한 뒤 슬롯에 끼우고 순간접착제로 고정합니다. 핀을 본체와 한 번에 출력하면 바닥 아래로 튀어나오는 부분에 서포트가 필요해서 이렇게 분리했습니다.

## 조정

```bash
pip install manifold3d trimesh matplotlib numpy
python3 make_insert.py --radio-slot 36 --phone-slot 24 --h-back 72
```

케이스를 끼운 실제 두께가 추정값(무전기 28, 폰 20)과 다르면 칸 폭을 조정하세요.

## 출력 권장

- PETG를 권장합니다. 여름에 차 안이 60도 이상 올라가면 PLA는 휠 수 있습니다
- 0.2mm 레이어, 벽 3, 인필 15~20%
- 본체 약 145cm³이고, 필라멘트는 대략 70~90g 정도 듭니다
